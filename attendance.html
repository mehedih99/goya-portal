Attendance Settings

These rules affect attendance calculations only; the main Admin/Staff Portal is untouched.

Automatic hourly shifts
Every 1 hour from the first shift through the last shift. No new shift is created after the last shift. Late = matched shift + grace period.

Live Attendance Workplace Verification

Web browsers cannot read a Wi-Fi SSID. Network verification uses the office public IP plus GPS radius.
